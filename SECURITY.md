# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Reporting a Vulnerability

**Do not open a public issue.** Email **security@sinemacula.co.uk** with:

- A description of the vulnerability
- Steps to reproduce or a proof of concept
- The affected version(s)

You will receive an acknowledgement within 48 hours, and a fix is coordinated with you before any public disclosure.

## Disclosure Policy

- Fixes are released as a new version
- The reporter is credited unless they prefer to remain anonymous
- Public disclosure follows the fix, coordinated with the reporter
